Curates background sound loops by focus level from local audio files.

## About

Curates background sound loops by focus level from local audio files.

## Features

- Dependency-free Node server
- Responsive, hand-written frontend
- Live API endpoints for stats and health
- Easy to restyle and extend

## Install

```bash
git clone https://github.com/synrayx/focusplaylist.git
cd focusplaylist
```

## Usage

```bash
npm start

open http://localhost:8080
```
